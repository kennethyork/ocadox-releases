How it keeps things quiet

Running a model hard for minutes at a time heats the GPU, and the fans ramp up to match. Ocadox manages the heat instead of letting it build.

Fan guard Free, on by default

  1. The agent takes a step. It reads a file, writes code, or runs a command with the model generating.
  2. Ocadox checks the GPU temperature. If it is above your target (60 °C by default), the agent pauses.
  3. The GPU cools, then work continues. Fans never need to spin up past their normal speed. No admin rights needed.

GPU power cap Optional

For NVIDIA cards, via NVML.

Set a wattage limit that applies while the model is generating. Less power means less heat in the first place. The live thermal panel shows temperature, fan speed, and watts as you work, so you can see what each setting does.

What you get

A real coding agent

Reads, edits, and searches files, runs shell commands with your approval, uses git, and can browse the web if you turn that on. Each chat works in the folder you set for it.

Any model, in-app

Download from the Ollama library or any GGUF on Hugging Face. Models are labelled by whether they fit your GPU.

Long chats that hold up

Older turns are summarised automatically, so the agent keeps track of the task instead of losing it to the context window.

Live thermal panel

GPU temperature, fan speed, and power draw, updated while you work.

Saved, searchable chats

Every conversation is kept locally and can be searched.

Private by design

Models run on your machine through Ollama. Nothing goes to a cloud service.

Bots that keep working

A bot is an agent you come back to: its own name and face, chat, project folder, model and instructions. Give it a job and close the window; it keeps going, and its result is waiting when you look again.

FAQ

Do I need Ollama?

Yes. Ocadox is built on Ollama, which runs the models. If you don't have it, Ocadox offers to install it for you on first launch (or get it from ollama.com). Ocadox then lets you download and manage models from inside the app.

Does it need admin rights?

No. Ocadox runs as a normal app, and the fan guard works by pausing the agent until the GPU cools, which needs no special permissions. The optional power cap does need administrator rights; Ocadox asks only if you turn it on.

Which GPUs are supported?

Windows and Linux (AppImage, .deb, .rpm) with an NVIDIA GPU get everything: live GPU telemetry, the fan guard and the optional power cap (via NVIDIA's NVML). macOS on Apple Silicon is in beta: the fan guard reads the chip's own temperature, and there is no power cap. AMD GPUs are not supported yet.

Is it really free?

Yes. Chat, the full coding agent with every tool, bots, model downloads, the fan guard, the power cap, saved chats and search are all free, with no time limit. Ocadox Pro is an optional one-time purchase for extra features.

Can bots keep working while I'm away?

Yes, while the PC is on. A bot keeps going with the window closed, and with Pro, Ocadox starts with Windows in the tray and runs each bot's routines on schedule, waking the PC from sleep if you ask it to. For bots that work while your laptop is off, keep them on an always-on PC (an old desktop or a mini PC is plenty) and connect from the laptop. Nothing runs while a PC is shut down.

Is connecting to my other PC safe?

The laptop pairs with a one-time code shown on the PC. The code also carries the PC's identity, so the laptop only ever talks to that PC, and the connection is encrypted. A paired laptop can only use the bots, and you can remove it at any time. Away from home, Tailscale (free) connects the two without opening ports on your router.

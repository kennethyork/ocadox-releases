# Ocadox

Local AI that keeps your GPU quiet. A desktop app on Ollama with chat and a full coding agent that waits for your GPU to cool between steps, so the fans stay at normal speed.

**Website:** https://kennethyork.github.io/ocadox-releases/

**Download:** [latest release](https://github.com/kennethyork/ocadox-releases/releases/latest) for Windows (`-setup.exe` or `.msi`), macOS on Apple Silicon (`.dmg`, beta) and Linux (`.AppImage`, `.deb`, `.rpm`). Ocadox updates itself from here.

## What's in it

- **Chat and a full coding agent** that reads and edits files, runs commands with your approval, uses git, and browses the web if you turn that on.
- **Fan guard and power cap:** the agent waits for the GPU to cool between steps.
- **Bots:** agents you come back to, each with its own chat, folder, model and instructions. They keep working, and keep their results, with the window closed.
- **Ocadox Pro** ($79, lifetime, up to 3 computers) adds bot routines on a schedule, starting with Windows to stay always on, using an always-on PC's bots from your laptop, checkpoints and undo, agent branches, and more: https://kennethyork.gumroad.com/l/wggyib

Bugs and ideas: [open an issue](https://github.com/kennethyork/ocadox-releases/issues/new).

Ocadox was called Hush before version 0.2.0.
